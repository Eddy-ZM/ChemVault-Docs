# Architecture

ChemVault Docs is the public Astro/Starlight product manual and integration-contract site. Content is versioned in the repository and built as static HTML. It documents user-facing product boundaries, canonical URLs, public API/event contracts, and release guidance; it is not an operational runbook or secret store.

All content is public. Local workspace paths, private Apple material, provider-console instructions containing identifiers, internal maintenance indexes, credentials, and unreleased product promises are excluded. Lab is the canonical extraction product; Extract appears only as a migration/compatibility topic.

There is no runtime authentication, private data, email, scheduled work, or automation. Public indexing is documented in `seo.md`.
