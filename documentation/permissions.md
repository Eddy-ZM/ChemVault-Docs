# Permissions

| Operation | Public visitor | Contributor | Product/service owner |
| --- | --- | --- | --- |
| Read/search public docs | Allow | Allow | Allow |
| Change content | Deny at runtime | Pull request | Review/approve owned surface |
| Declare product/contract authority | Deny | Propose with evidence | Approve and coordinate implementation |
| Access secrets/private runbooks | Deny/not present | Deny/not present | Use private operational system, not this repo |

Repository branch/review controls are the only privileged boundary.
