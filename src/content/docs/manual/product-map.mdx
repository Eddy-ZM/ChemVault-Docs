## 工作产品

| 产品 | 入口 | 权威职责 |
| --- | --- | --- |
| Files | [file.chemvault.science](https://file.chemvault.science) | 文件上传、存储、组织、分享与删除。 |
| Lab | [lab.chemvault.science](https://lab.chemvault.science) | 科学文件分析、批处理、结果、审核与导出。 |
| User Center | [user.chemvault.science](https://user.chemvault.science) | 账号、资料、安全、服务权限、数据导出与账号删除。 |
| Notifications | [notify.chemvault.science](https://notify.chemvault.science) | 通知、消息、产品更新和返回权威产品的深链接。 |
| Mail | [mail.chemvault.science](https://mail.chemvault.science) | 邮箱、邮件客户端配置和邮件管理。 |
| Molecule Studio | [model.chemvault.science/molecule](https://model.chemvault.science/molecule) | 分子搜索、SMILES、绘制、PDB 与三维查看。 |
| Forms | [forms.chemvault.science](https://forms.chemvault.science) | 私密反馈、Bug、合规与安全报告。 |

## 边界原则

- Files 管文件；Lab 管分析与结果；Notifications 只传递状态和深链接。
- User Center 是账号生命周期唯一入口。
- Download Center 只启用具有 HTTPS 来源、版本、SHA-256 和文件大小的发布资产。
- ChemVault Extract 是历史兼容入口，不再承接新功能；新工作流使用 Lab。
- Apple 应用保持原生 SwiftUI，不以 WebView 作为主界面。
