title: ChemVault Extract 迁移说明
description: ChemVault Extract 进入维护期，新的科学分析工作流迁移到 ChemVault Lab。
---

ChemVault Extract 已进入维护迁移期，不再作为新功能和新项目的首选入口。

- 新的文件分析、批处理、结果审核与导出：使用 [ChemVault Lab](https://lab.chemvault.science) 和 [Lab 教程](/manual/lab/)。
- 源文件管理与分享：使用 [ChemVault Files](https://file.chemvault.science)。
- 任务完成与失败提醒：使用 [ChemVault Notifications](https://notify.chemvault.science)，并从通知返回 Lab。
- 账号导出和删除：使用 [ChemVault User Center](https://user.chemvault.science)。

维护期兼容 API 仅用于平稳迁移，不代表继续扩展独立 Extract 产品。迁移前请完成数据导出，并验证共享工作区和付费订阅的处理方式。
