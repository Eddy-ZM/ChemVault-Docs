ChemVault Lab 是科学文件分析和结果管理的权威产品，入口为 [lab.chemvault.science](https://lab.chemvault.science)。

## 推荐工作流

1. 在 [ChemVault Files](https://file.chemvault.science) 选择文件并点击 **Process in Lab**。
2. Lab 验证登录身份和文件读取权限后导入对象；浏览器不会获得服务密钥。
3. 确认实验名称、文档类型、输出语言和导出格式。
4. 启动分析并等待真实作业状态，不把排队状态当作完成。
5. 在结果页审核摘要、表格、计算和缺失值。
6. 下载 JSON、Markdown、LaTeX 或 XLSX；Notifications 的完成消息会直接返回该结果页。

## 数据与安全

- Files 保留源文件权威副本；Lab 保存分析所需的私有副本和结果。
- 未识别信息应显示为 Missing 或 null，不应自动编造。
- 账号导出和删除由 User Center 发起，并覆盖 Lab 中属于该用户的分析、文件和事件数据。
- 产品分析不记录文件内容、文件名、搜索文本、邮箱、IP 或原始用户 ID。

历史 ChemVault Extract 仅在迁移期保留兼容能力。新项目、批处理和结果编辑应使用 Lab。
